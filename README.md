# 小趣社
#### 项目背景
如今，物业管理系统是现代小区不可缺少的一部分，而互联网行为已经融入人们的生活当中，网上报修、缴费等相关业务办理已经代替传统物业管理模式，做这个让互联网与传统行业进行融合的“互联网+”项目就很有必要。

#### 项目介绍
这是一个基于ssm的互联网+小区管理+社区交流的项目，使用到的技术点有：使用Mybatis分页插件PageHelper，使用redis做Mybatis的二级缓存，使用Spring 自带的md5加密工具类，使用Tomcat搭建图片服务器，maven项目，使用ssm框架，后台bootstrap前端框架，轮播图，富文本编辑框等等
