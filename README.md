# CM-SSM

#### 项目介绍
基于ssm的互联网+小区管理+社区交流的项目，使用到的技术点有：使用Mybatis分页插件PageHelper，使用redis做Mybatis的二级缓存，使用Spring 自带的md5加密工具类，使用Tomcat搭建图片服务器，maven项目，使用ssm框架，后台bootstrap前端框架，轮播图，富文本编辑框等等
